     is never applied to the running process (workers fork before
     `Decrees.load`; write is append-only) — SSO died with

     data (`EACCES mkdir`, SSO hung at "Hashing your password"). Fixed:
     `owner` option in the btrfs module; cryptpad moved from DynamicUser
     to a static `cococoir-cryptpad` user; jellyfin metadata/media
     chowned to `jellyfin`.
